# ATHENEA STUDIO — WEB

Tienda de moda online con diseño atemporal, carrito de compras, favoritos y envíos a Colombia.

## Vista previa

> Proyecto de desarrollo web personal — tienda de moda femenina hecha en Medellín, Colombia.

## Tecnologías

- HTML5, CSS3, JavaScript Vanilla
- FontAwesome 6.4 para iconos
- Google Fonts (Cormorant Garamond, Inter, Montserrat)
- LocalStorage para persistencia del carrito y favoritos

## Funcionalidades

- Catálogo de 8 productos con precios en pesos colombianos (COP)
- Filtros por categoría, precio y orden
- Carrito de compras con persistencia (localStorage)
- Cálculo de envío según ciudad colombiana:
  - Medellín → Envío gratis
  - Bogotá / Cali / Barranquilla → $15.000 COP
  - Otras ciudades → $25.000 COP
- Lista de favoritos (wishlist)
- Búsqueda de productos en tiempo real
- Modal de detalle de producto con selector de talla y color
- Menú responsive para móviles
- Newsletter subscription
- Notificaciones toast animadas
- Navegación con efecto scroll
